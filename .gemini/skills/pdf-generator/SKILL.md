# PDF Report Generator

Synthesizes technical emergency data into a portable, offline-ready PDF document.

## Workflow
1. **Data Collection**: Aggregates outputs from `fallout-predictor`, `risk-analyst`, `logistics-navigator`, and `psych-counselor`.
2. **Visual Integration**: Embeds maps and charts generated by the `data-visualizer`.
3. **Template Rendering**: Populates a structured PDF template (using `fpdf2` or similar) with localized survival instructions and Points of Interest.
4. **Finalization**: Produces a compressed PDF file optimized for low-bandwidth transmission.

## Resources
- `assets/templates/`: Base layouts for Emergency Briefs and Technical Reports.
- `scripts/generate_report.py`: The core engine for PDF construction.
