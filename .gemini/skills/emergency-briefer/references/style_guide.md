# Emergency Communication Style Guide

## 1. The BLUF Model (Bottom Line Up Front)
- Always start with the single most important action (e.g., "SHELTER IMMEDIATELY").
- State the threat clearly in the first sentence.

## 2. Jargon Translation
| Technical Term | Readable Alternative |
| :--- | :--- |
| **Initial Radiation / Dose** | **Lethal Radiation Zone** |
| **Thermal Pulse** | **The Flash / Fireball** |
| **Overpressure (psi)** | **Blast Impact / Structural Damage** |
| **Mach Stem** | **Enhanced Blast Zone** |
| **Fallout Plume** | **Radioactive Dust Path** |

## 3. Prioritization Logic
1.  **Life Preservation**: What to do RIGHT NOW (0-5 mins).
2.  **Immediate Shielding**: Where to go (5-30 mins).
3.  **Long-term Survival**: What to monitor (1-48 hours).

## 4. Formatting Standards
- Use `###` for main headers.
- Use `**` for emphasis on actions.
- Use `-` for checklists.
- Avoid large blocks of text; limit paragraphs to 2-3 sentences.
