# Skill Optimizer

Ensures existing skills remain state-of-the-art and operationally efficient.

## Workflow

1.  **Audit Skill**: Review an existing skill's `SKILL.md`, scripts, and references.
2.  **Identify Improvements**:
    - **Data**: Suggest more reliable or faster APIs/datasets.
    - **Logic**: Identify edge cases or computational inefficiencies in scripts.
    - **Safety**: Enhance protocols based on updated medical or physics data.
3.  **Propose Changes**: Provide specific `replace` or `write_file` instructions for the agent to execute.

## Optimization Criteria

- **Autonomy**: Reduce dependence on fragile external services.
- **Speed**: Optimize script execution for immediate emergency response.
- **Clarity**: Improve instructions for better agent adherence.
